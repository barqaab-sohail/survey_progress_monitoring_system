# Mobile submission, row media and editable groups

The editor now contains Details and S/E rows tabs. PV records and photo controls remain inside their owning S/E row. Historical unlinked records remain accessible in the S/E page's "Previously saved unlinked records" expansion; this update neither deletes them nor guesses a row assignment.

New S/E rows continue to default to the assigned team's two-digit identifier. Users may edit each row independently. Exactly two ASCII digits are accepted, including `00` and leading zeros. Explicit edits are preserved by local storage, immutable queued submissions, acknowledgement, reopening and backend updates. Team renumbering does not overwrite saved row values.
