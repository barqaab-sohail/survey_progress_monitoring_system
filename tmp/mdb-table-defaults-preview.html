Choose the MDB table below, then enter the values to use for this project. The friendly label explains each setting; the column name matches Microsoft Access exactly.

Example: InstMymSwDevPos stores the switch status for each transformer. SectionId is filled from the transformer automatically. Device code M, position Closed (0) and year indexes 0–10 create 11 records per transformer.

Year 0 means the base year in SAI_Control, not calendar year 0. Blank means NULL where permitted; 0 is a value. Saving creates a configuration revision and requires fresh survey approval and JSON export. The settings are included once in the JSON used for local MDB generation.
